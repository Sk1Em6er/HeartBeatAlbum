# 心动纪念册 💗

整个屏幕铺满大小不一的长方形（横的竖的混着来），
中间一颗**固定大小**的爱心像一扇窗：**窗内完全清晰，窗外微微透明 + 模糊**。

---

## 怎么打开

**方法一（最方便）**：双击桌面上的 **心动纪念册** 图标 ✅

**方法二**：双击项目文件夹里的 `启动心动纪念册.bat`

**方法三（开发者）**：在本文件夹打开终端，运行 `npm start`

## 画面构成

```
┌────────────────────────────────────────────────┐
│  模糊 + 微微透明的长方形（铺满整个窗口）    ⚙  │
│        ╭──────────────────╮                    │
│       ╱   清晰的长方形      ╲   ← 爱心像一个窗  │
│      │   ▭  ▭   ▭   ▭  ▭    │     窗内完全显示 │
│       ╲     ▭   ▭   ▭      ╱                    │
│         ╲      ▭        ╱                      │
│           ╰─────∨─────╯                        │
└────────────────────────────────────────────────┘
```

- **两个图层**：爱心**外面**是一层（模糊 + 半透明），爱心**里面**是另一层（完全清晰）。
  两层是**同一份**长方形图案，用爱心路径裁出来，所以窗内窗外严丝合缝对得上。
- **爱心大小固定**，永远居中，**不会随滚轮变化**。
- 长方形**横竖混排**、大小随机但互不重叠，铺满整个窗口（连窗口边缘外也多画了一圈，模糊到边缘不会变淡）。

| 操作 | 说明 |
| --- | --- |
| **滚轮** | 以**鼠标所在位置为焦点**柔和地放大 / 缩小长方形（爱心固定不动，逐帧缓动，不重排版） |
| **每次打开** | **窗口标题栏**（任务栏上那个）会变成「心动纪念册 · 随机一句暖心话」；屏幕里的标题保持「心动纪念册」不变，设置面板里显示同一句 |
| **按住拖动**（不用等长按，一动就变抓手光标） | 移动整个画面（方块阵跟着走）；松手后不会误触"打开方块"，而**单纯点一下仍然正常打开方块** |
| 鼠标移动 | 指到哪个长方形，哪个就亮起描边（判定范围和画出来的方块**像素级一致**）；**移到照片上会放大浮起做预览**（约 1.15~1.9 倍，带投影，缓动动画） |
| 点击长方形 | 空格子 → 弹窗里**从电脑选图 / 从图片库选图 + 写简介**；有照片的 → 显示大图，文字**一个字一个字跳出来** |
| 放照片之后 | **照片直接铺在这个方框里**（不裁切、不拉伸），而且**方框会自动变成这张照片的长宽比** —— 横照片给横框、竖照片给竖框；照片就留在你放它的位置，整个画面依旧是随机方框铺满的效果 |
| 弹层里 `↻ 重新播放` / `编辑` / `删除照片` | 重看动画 / 改内容 / 清空这一格 |
| `Esc` | 关掉弹层 |
| **⚙ 设置 → 图片库 → ＋ 导入图片** | 不用点方块，直接把电脑里的图片传进图片库 |
| 右上角 **⚙ 设置** | 长方形大小、外部模糊、外部透明度、爱心线条粗细、打开数据文件夹 |

有照片的长方形是**深粉色 + ♥**，还会把照片本身铺在格子里（窗内清晰、窗外模糊）。

## 图片库（传图功能）

弹窗里除了「📷 从电脑选择」，还有 **「🖼 从图片库选择」**：

- **导入图片**：点「＋ 导入图片」，可以一次多选，图片会被复制进图片库；
- **直接丢进去也行**：设置面板里点「打开 pictures 文件夹」，把图片拖进去，回到弹窗点一下「从图片库选择」就能看到；
- 图片库里点缩略图即可选中；鼠标移上去右上角有 `×` 可以删掉这张；
- 选中后保存，这张图会**复制一份进相册自己的 photos 目录** —— 所以之后删掉图片库里的原图，相册里的照片也还在。

图片库位置（设置面板里可以直接打开）：

```
<用户数据目录>  album-data/
    album.json     每一格的文字、照片文件名、位置、长宽比，以及设置
    photos/        相册自己的照片（每张都复制一份进来，独立存储）
    pictures/      图片库（你往里丢图 / 用「导入图片」传图）
```

## 怎么画出来的

1. **爱心**：经典参数方程 `x = 16sin³t`，`y = 13cos t − 5cos2t − 2cos3t − cos4t`，取 720 个点。
   底部保持**参数方程原本的尖**（`TIP_SLOPE = 0`）——干净、细、和最初一样。
   如果哪天想让底部"夹角大一点、不那么尖"，只改一个数就行（`heartGeom()` 里）：

   ```js
   const TIP_SLOPE = 0;      // 0 = 原始尖点；>0 = 把底部改成有明确夹角的直线收尖
   const TIP_DEPTH = 0.14;   // 加宽只作用在底部 14% 高度内
   ```

   | TIP_SLOPE | 0 | 0.42 | 0.58 | 1.0 |
   | --- | --- | --- | --- | --- |
   | 底部尖角 | 原始（很细） | 45° | 60° | 90° |

2. **长方形**：对铺图案的区域做**随机对半切（BSP）** —— 区域大于随机上限就沿长边按随机比例切开。
   于是既有横长方形也有竖长方形，大小参差、互不重叠。
   铺的范围比窗口大 `COVER = 2.6` 倍，所以怎么放大都不会露出边缘（当前整图 979 块，屏幕上约 430 块）。
3. **几何缩放（这是滚轮顺滑的关键）**：滚轮**不重新排版**，只是给整个图案层加一个 `scale` 变换，
   并且每次缩放都把「鼠标底下那个图案点」重新对齐到鼠标位置 —— 所以是盯着鼠标位置放大，而且逐帧缓动、丝滑。
   实测动画帧间隔平均 10.5ms（60fps 标准是 16.7ms）。
4. **两层**：两块 canvas 画同一份图案 ——
   - 下面那块（爱心外）：`filter: blur() + opacity`（数值在设置里调）
   - 上面那块（爱心内）：`clip-path: url(#heartClip)` 裁剪成爱心，并且**先铺一层浅粉底**再画方块 ——
     这样爱心里的缝隙是浅粉色（看着是一整颗实心的心），而不是透出背景的"洞"（尤其心尖那里很窄，否则会显得空）
5. **照片就住在原来的方块里**（不再为了照片改变方块形状）
   - **方块大小自动算**：按"爱心要装下 1.4 倍照片数"定方块尺寸 ——
     33 张照片时方块约 32~92（图案单位）、缝约 8px、爱心内约 45 个方块，照片占其中 33 个；
   - **方块照旧随机对半切**（横竖混排、大小参差）—— 就是原来那种凌乱感，方块形状**完全不为照片改**；
   - **分派**：先按"爱心面积 ÷ 照片数"在爱心里撒一层均匀座位（带抖动、固定种子打乱），
     每张照片认领**离自己座位最近**的方块（在附近几个里挑长宽比最合适的，少裁一点）；
     实测各环照片密度 **0.74x ~ 1.30x**（1.0 = 完全均匀），既没聚在中心也没挤到边上；
   - **照片按方块裁剪铺满**（cover）：方块是横是竖随机，所以照片会按方块形状裁掉一点边 ——
     换来的是"照片就是方块本身"的整洁感，而不是方块被照片撑成各种规格。

6. **照片**：每张照片先缩成最长边 520px 的小图缓存（**保留原始长宽比**），再 cover 铺进格子里，省内存。
7. 换布局（改窗口大小）时，每格记录了自己的归一化坐标，照片会**尽量留在原来的位置**。

实测两个图层的差别：**边缘锐利度 48 : 2**（窗外被明显模糊），**色彩饱和度 53 : 32**（窗外明显变淡）。

## 背景音乐

**默认自带**：不依赖任何音频文件，用 Web Audio 现场合成的一段**温馨小提琴曲** ——

- **音色（偏温馨）**：一根正弦做**厚实的芯** + 3 根略失谐的锯齿波只留一点弓弦毛边；
  **慢起弓**（0.26 秒）+ `5.4Hz` 颤音（起弓后渐入，像真人揉弦）；
  `1200Hz` 琴身共振（木头箱体）+ `300Hz` 低频架 `+3.2dB`（暖厚）+ 低通 `2600Hz`（柔和不刺）
  + 高频只留 `+1dB` 的一点点晶莹 + 混响尾巴也压到 `3000Hz`（不发亮）+ **3.4 秒大厅混响**
- **曲子**：A 小调、58 BPM、8 小节一句（`Am–F–C–G`），旋律是能哼出来的那种，句尾留气口
- **曲子**：A 小调、64 BPM，8 小节一句（`Am–F–C–G`），旋律是能哼出来的那种，句尾留气口；
  下面垫一层弦乐铺底 + 大提琴低音，偶尔一颗高音泛音
- 打开软件**缓缓淡入 2.5 秒**；设置面板可随时开关、调音量（记住选择）

**想换成真的小提琴曲**（推荐，效果最好）：设置 → 音乐来源 → **「＋ 导入音乐」**，
选中的 mp3 / flac / m4a 会复制进 `music` 文件夹并**立刻开始播放**（不用重启）；
也可以点「打开文件夹」直接把文件拖进去。多首会按顺序循环，设置里会显示"第几首 / 曲名"。
`music` 文件夹空了就自动退回内置合成曲。

> 我没有办法把有版权的录音打包进程序，所以这一步需要你自己放文件。
> **免费且合法的来源**：`musopen.org`（公有领域古典乐录音，可直接下载）；
> **适合这颗爱心的暖心小提琴曲**：埃尔加《爱的致意》、马斯涅《沉思曲》、
> 帕赫贝尔《卡农》、巴赫《G 弦上的咏叹调》、圣桑《天鹅》、克莱斯勒《爱的喜悦》。

```
%APPDATA%\heartbeat-albumlbum-data├── photos\      相册里的照片
├── pictures\    图片库（选图用）
└── music\       背景音乐（放了文件就用它，没放就用内置合成小提琴曲）
```

## 想微调哪里？

| 想改的东西 | 改哪个文件 |
| --- | --- |
| 爱心形状（胖瘦/尖度） | `src/renderer.js` 的 `heartGeom()` 里那条参数方程 |
| 底部尖角角度 | `heartGeom()` 里的 `TIP_SLOPE = 0`（0 = 原始尖点；0.42→45°、0.58→60°、1.0→90°），影响范围 `TIP_DEPTH = 0.14` |
| 爱心大小 | `HEART_FILL = 0.78`（占窗口较小边的比例） |
| 长方形大小 | `BASE_MIN / BASE_MAX`（基准尺寸），或直接用滚轮 / 设置滑块 |
| 缩放范围 | `ZOOM_MIN / ZOOM_MAX`（默认 1 ~ 2.6） |
| 缩放柔和程度 | `EASE = 0.16`（越小越绵），滚轮灵敏度在 `wheel` 里的 `0.0011` |
| 图案铺多大 | `COVER = 2.6`（越大越不容易露边，但块数更多） |
| 缝隙宽度 | `draw()` 里的 `gap = 9` |
| 爱心内的底色 | `draw()` 里的 `baseFill` |
| 切分比例（更方/更长） | `buildBlocks()` 里的 `ratio = 0.3 + rnd()*0.4` |
| 外部模糊 / 透明度默认值 | `DEFAULT_SETTINGS` 里的 `blur`、`outsideAlpha` |
| 长方形的颜色 | `draw()` 里的 `emptyFill` / `filledFill`（以及爱心内的底色 `baseFill`） |
| 照片方块大小 | `arrangePhotos()` 里的 `S0 = sqrt(PHOTO_AREA)`（基准短边）、`jitter`（`0.70 + rnd*0.65` 的尺度自由度）、`PHOTO_MIN / PHOTO_MAX` |
| 照片占地比例 | 同上的 `budget = 0.72*hw*hh*0.38`（38% 给照片，其余留给周边方块） |
| 照片方块大小 | `PHOTO_AREA`（目标面积 15000）、`PHOTO_MIN / PHOTO_MAX`、可用面积比例 `hArea * 0.42` |
| 照片排布 | `arrangePhotos()`：座位间距 `seatStep`、抖动系数 `0.6`、松弛轮数 `400`、照片间隙 `PAD = 6` |
| 中心/边缘的大小差 | `arrangePhotos()` 里的 `k = 1.20 - 0.25 * 距离比例` |
| 悬停预览倍率 | `previewScale()` 里的 `130 / 最小边`、上下限 `1.15 ~ 1.9` |
| 普通方块大小 | 同上的 `TILE_MIN / TILE_MAX` |
| 外框渐变色 | `src/index.html` 里 `<linearGradient id="heartStroke">` |
| 标题样式 | `src/styles.css` 的 `.topbar .title` 和 `.topbar .quote` |
| **内置小提琴曲** | `src/music.js`：`BPM` 速度、`CHORDS` 和声、`MELODY` 主旋律（`[起始拍, MIDI音高, 时值]`）、`bow()` 里的 `attack` 起弓时长 / `vib` 颤音音分 / `bright` 低通亮度 / `detune` 失谐；混响时长在 `ensure()` 里；默认开关和音量在 `DEFAULT_SETTINGS` 的 `music / musicVolume` |
| **暖心话文案** | `src/renderer.js` 里的 `PHRASES` 数组（现在 10 句，随便加）。每次打开随机挑一句写进窗口标题（`document.title`），设置面板显示同一句 |
| 文字跳动速度 | `typeText()` 里的 `delay = 78`（毫秒） |
| 应用图标 | `assets/icon.ico`，或 `npm run icon` 重新生成 |

改完重新双击图标即可生效。
